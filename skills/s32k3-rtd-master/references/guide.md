# guide 参考文档

> 本文件是 SKILL.md 中 `guide` 命令的**次选**路由。确定性操作请走首选脚本
> `python scripts/cmd/cmd_guide.py <关键词>`。

## 何时读这份文档

- 需要了解 `output/guide_<关键词>.md` 的生成结构
- 抽取结果缺代码块/标题，需要人工核对
- 要把指导产物交给别人前确认口径

## 产物结构

脚本对每个命中的 `references/<外设>.md` 做**保序抽取**：

1. 文件头：`# 写码指导: <关键词>` + 参考工程绝对路径清单
2. 每个来源文档一节：文档名 + 绝对路径 + 代码块计数
3. 节内内容按原文顺序保留：`#`~`####` 级标题 + 完整 fenced code block（含语言标注，内容逐字符原样）

## 抽取口径

- 代码块：成对的 ``` 围栏整体摘录（含围栏行），内部内容不动一个字符
- 标题：正则 `^#{1,4}\s+`；正文段落、表格、mermaid 图**不**抽取（指导以代码为主）
- mermaid 时序图在原文档（references/<外设>.md 第 2 节）里，要时序图直接读原文档

## 使用约定

- 产物只写 `output/`（已 gitignore），不回写 references
- 同关键词重复运行会覆盖旧产物
- 拿到指导后写码：沿用示例的 API 调用序列与参数写法，禁止"顺手改写"
