### B.6.2 MCM module changes 

- In MCM register descriptions, updated the reset values for LMEM_DESC_3 (0x85264000) and LMEM_DESC_4 (0x85446000). 

- In MCM register descriptions, updated the reset values for LMEM_DESC_0 (0x87060000h), LMEM_DESC_1 (0x87042000h) and LMEM_DESC_2 (0x87042000h). 

- In Local Memory Descriptor 0 (LMEM_DESC_0), updated the note to "The reserved bits can be read and written (instead of read as zero and write ignored). Setting any of these bits does not have any functional impact".
