# 盘问规则（模式一 · grill）

来源：grill-me v3.0.0（github.com/tkersey/dotfiles）+ grill-with-docs（github.com/cboyd10/claude-config，Matt Pocock）。

## 判断归属（四分法）

每个信息缺口先归入四类，只有第四类才进问题链：

| 信息类型 | 归属 | 动作 |
|---|---|---|
| 事实（代码/文档/配置/报错里写着） | 研究 | 读代码，禁止问用户 |
| 模型可定（有行业常规做法、明显默认值） | 模型 | 定默认值，终稿声明"默认 X，依据 Y" |
| 用了才知道（性能、行为验证类） | 探针 | 终 prompt 里安排验证步骤（日志/单测/断点） |
| 用户必须拍板（过物质性测试） | 用户 | 进问题链 |

## 物质性测试

一个问题只有满足以下任一条才算用户级决策，否则不问：

- 答案改变目标或范围（做 A 还是做 B 是两件事）
- 答案改变验收标准（"能跑通"还是"过 MISRA 检查"）
- 答案引入风险或兼容性破坏（改生成物、动启动链、改公共头）
- 操作不可逆（删数据、force push、覆盖 mex 生成物）
- 多个选项成本相近且无客观优劣（口味题：命名、风格）

不满足 → 自己定，终稿声明。技术细节不推给用户。

## 问法

- **原子**：一问一个决策，不打包。
- **每问必带推荐答案 + 一句理由**。推荐来自研究结论，不拍脑袋。
- **封闭选项** A/B/C，末位固定 `C. 其他，请说明`。
- **不推锅**：技术选型自己推荐最优解并说明取舍，不把功课留给用户。

## 回答处理

| 用户反应 | 处理 |
|---|---|
| 答非所问 | 完整句澄清一次（唯一允许的完整句场景），重新问原问题 |
| 部分回答 | 只锁已答部分，未答的下一轮重问 |
| 改口 | 后答覆盖前答；依赖它的后续问题全部重算 |
| 沉默 / 跳过 | 按推荐值锁定，标注"用户未确认" |
| "不要管 / 别问了 / 直接干 / 随你" | 全部剩余问题按推荐值锁定，进度直接拉到 100%，逐项标注"用户未确认" |

## 收尾判据（全部满足才算 100%）

- 问题链清空（全部答完，或全部按推荐锁定）
- 每个决策点有明确结论 + 来源标注（用户选 X / 按推荐锁定）
- 无悬空依赖（前问改口后，后问已重算并重新确认）

## 反模式

| 反模式 | 正解 |
|---|---|
| 把技术选型推给用户（"你想要哪种方案？"不给推荐） | 给推荐 + 理由 |
| 问代码里写着的东西 | 先研究 |
| 一轮甩 5 个问题 | 一次一问 |
| 凑数空问（问了对结果没影响） | 砍掉 |
| 进度条不随回答更新 | 每轮必重新显示 |
| 100% 后还要用户再确认一次 | 盘问即确认，贴全文立即执行 |
| 问题超过 5 个 | 砍到 5 个以内，其余按推荐默认并声明 |
